# 🔥 Streak Task Manager

Duolingoのストリーク（連続達成）機能にインスパイアされた、モチベーション維持特化型のタスク管理アプリです。
モダンなダークテーマと直感的なUIで、日々のタスク消化をゲーム感覚で楽しめます。


## ✨ 特徴

- **🔥 ストリーク機能**: 毎日タスクを完了して、連続記録を伸ばそう！
- **📊 視覚的な進捗管理**: 完了したタスクやストリークの履歴をグラフで確認できます。
- **⏱️ ポモドーロタイマー**: 集中力を高めるためのタイマー機能を内蔵。
- **💻 デスクトップアプリ**: Electron製で、ネイティブアプリとして動作します。
- **📝 ノート機能**: タスクに関連するメモやアイデアをサッと記録。

## 🛠️ 使用技術

- **Core**: HTML5, CSS3, JavaScript (Vanilla)
- **Desktop Framework**: Electron
- **Graph**: Chart.js
- **Icons**: FontAwesome

## 🚀 実行方法

### 必要条件
- Node.js (v18以上推奨)

### インストールと起動

```bash
# リポジトリをクローン
git clone https://github.com/Ta1-0301/Streak-Task-Manager.git
cd streak-task-manager

# 依存関係のインストール
npm install

# 開発モードで起動
npm start
```

## 📦 ビルド（Windows向け）

```bash
# プロダクションビルドの実行（distフォルダにexeが生成されます）
npm run build
```
